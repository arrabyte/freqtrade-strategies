# BBReversion

🔒 **Private, live-traded strategy — code not published here.**

This is a Bollinger Band mean-reversion strategy for crypto futures, running
live since mid-2026. It's actively maintained and its weekly performance is
published for subscribers on Substack, alongside the reasoning behind
allocation changes and regime shifts.

No parameters, entry/exit logic, or backtests for this strategy are shared
publicly. This folder exists purely as a pointer for anyone landing on this
repo from [`SilvanStrategy`](../SilvanStrategy.py) or the accompanying
article — the strategies actually traded live are not built (or tested) the
way that one deliberately is.
